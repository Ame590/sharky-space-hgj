# SHARKY SPACE（HGJ）

HAI SHARKY 是海管家的 AI 智能伙伴。

它敏锐感知运价与舱位变化，把询价、订舱、舱单与报关化繁为简，陪伴每一次国际运输聪明启航、顺畅抵达。

## 品牌主张

- MISSION：让智能物流支撑多彩世界的转动
- 持续进化
- Make it happen
- POWER：AI

## 本地运行

```bash
npm install
npm run dev
```

## 技术栈

React 19 · Vinext · Vite · TypeScript
